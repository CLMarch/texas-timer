德州扑克盲注计时器 - iPad 独立部署包
=====================================
用途：把本工具放到任意 https 静态托管后，iPad Safari 打开一次 -> 添加到主屏幕 -> 永久离线独立使用（断网、关电脑都能用）。

部署（任选一种载体，均为静态托管）：
1. GitHub Pages / Vercel / Netlify / 公司内网静态站等
2. 把这 4 个文件原样上传到网站根目录（文件名不要改，尤其 sw.js 必须和 HTML 同目录）

iPad 使用：
1. 确认 iPad 能访问到该 https 地址（如 https://你的域名/德州盲注计时器.html）
2. Safari 打开，点【分享】->【添加到主屏幕】，起名"德州计时器"
3. 之后从主屏图标打开，断网也能用，进度自动保存

说明：
- 局域网 http（如 http://192.168.x.x）无法启用离线缓存，必须 https 或 localhost
- 改功能后，把新版 HTML 重新上传覆盖即可，iPad 联网打开会自动更新
